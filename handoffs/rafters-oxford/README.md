# Rafters (Oxford, MS) — Design Handoff Package

Compiled photo packet from **Rafters Music and Food**, 1006 E Jackson Ave, Oxford MS — an MCTV
Elite Advertising venue partner. Packaged for creative handoff.

**344 photos · 1.81 GB · 2 shoot nights (Sept 27–28, 2024)**

## Start here

1. **`HANDOFF-BRIEF.md`** — venue profile, network performance, session breakdown, creative direction,
   and open items. Read this first.
2. **`contact-sheet.html`** — visual index of all 344 photos with session filters. Open in a browser
   (thumbnails stream from Google Drive, so it needs a connection).
3. **`manifest.csv`** — flat inventory for selection tracking in a spreadsheet.
4. **`manifest.json`** — same data plus venue/source metadata, for programmatic use.

## Source assets

Full-resolution originals live in the venue's Google Drive folder, not in this repo:

<https://drive.google.com/drive/folders/18YmDNfS5TqEQySsVuCj4BYcpNcClAYtW>

The folder is link-shareable. To grab everything at once, open it, select all, and use Drive's
**Download** action. For individual files, every row in the manifests carries a direct
download URL.

## Regenerating

The manifests were generated from a direct enumeration of the Drive folder (deduplicated by file ID
and verified against independent capture-time slices). If the venue adds photos, re-enumerate the
folder and rebuild rather than editing the manifests by hand.
